# Vowframe English website

Local prototype for a custom AI wedding film service. The enquiry form is a visual demo and does not send or store data.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory dist
```

Then open http://127.0.0.1:8768/ . This repository does not enable GitHub Pages or publish the website.

## Project files

- `dist/` — static site and currently used visual assets
- `ASSET_SOURCES.md` — image provenance and publishing considerations
- `LOGO_GUIDE.md` — proposed visual identity
- `SEO_GEO_PLAN.md` — search and generative discovery plan

The photographs are user supplied visual references. Confirm rights and consent before public marketing. The SVG logo is a design proposal and should be checked before trademark use.
